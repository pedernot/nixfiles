# Theming

This repository uses Stylix as the single source of truth for theming.

## Ownership

- NixOS-level shared Stylix settings live in `linux/stylix.nix`.
  - `stylix.base16Scheme`
  - `stylix.polarity`
  - `stylix.fonts`
  - `stylix.autoEnable`
- Portable Home Manager target opt-in lives in `shared/theme.nix`.
- Linux-only Home Manager targets live in `linux/theme.nix`.

All NixOS hosts import `linux/stylix.nix` and should share the same
theme settings.

## Current target policy

`shared/theme.nix` keeps `stylix.autoEnable = false`. Shared and Linux
target modules only enable targets that are verified against this config:

- foot (colors only; fonts/inputs/opacity explicitly controlled)
- tmux
- bat
- btop
- fzf
- starship
- yazi
- zathura

## App-specific notes

- `foot`: color include is generated by Stylix, but font and dpi are managed in
  `linux/terminal.nix` (and host overrides where needed).
- `tmux`: color palette is owned by Stylix. Keep behavior/keymaps in
  `tmux.conf`.
- `nvim`: uses `base16-harmonic16-dark` directly in
  `nvim/lua/config/colors.lua` and does not depend on `tinty`.

## Change workflow

When adding a new Stylix target:

1. Add exactly one target in `shared/theme.nix` or `linux/theme.nix`, according
   to platform ownership.
2. Rebuild and verify visuals.
3. Keep or revert based on result.

Avoid host-specific Stylix overrides unless there is a deliberate, documented
reason.
